
| Вопрос                                      | Целевой результат через 12 месяцев                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Какие системы остаются**                  | **FU Core, FU CRM, FU Cards и FU Loans** - основа операционного обслуживания. **RB Core, RB CRM, RB Cards и RB Loans** сохраняются только для ещё не перенесённых портфелей и функций, с явно определёнными границами ответственности. Введены в эксплуатацию **Customer MDM, Product / Reference MDM, API Gateway и интеграционные сервисы, Kafka, корпоративный DWH, Lakehouse на Iceberg и Trino, Airflow, DataHub и единый логический BI-слой**. Существующая ESB может остаться частью интеграционного слоя, если соответствует целевым требованиям. |
| **Какие системы выводятся из эксплуатации** | **RB DWH перестаёт быть самостоятельным контуром формирования отчётности** после переноса всех включённых в миграцию отчётов и зависимостей. Отключаются дублирующие витрины, загрузки и дашборды **RB BI**, временные обмены и заменённые point-to-point-интеграции. Отдельные функции или экземпляры **RB CRM / Core / Cards / Loans** отключаются только после переноса обслуживаемого ими объёма. Полное отключение всех RB-систем не объявляется обязательным результатом первого года.                                                              |
| **Какие данные мигрируются**                | Клиентские записи FU/RB сопоставляются в **Customer MDM**, продуктовые и справочные данные - в **Product / Reference MDM**. История всех **14 бизнес-сущностей** в согласованной глубине переносится в **Lakehouse**, а проверенная отчётная детализация и витрины - в **DWH**. Перенос действующих счетов, договоров и других операционных записей между банковскими системами выполняется отдельно, по утверждённым портфелям.                                                                                                                          |
| **Какие потоки переключаются**              | Клиентские и справочные изменения распространяются через **MDM → Kafka → интеграционные сервисы → потребители**. Изменения операционных данных поступают через **CDC / доменные события → Kafka → аналитическую платформу**. Отчёты и BI переключаются с разрозненных FU/RB-витрин и прямых аналитических запросов к OLTP на корпоративный DWH. Операционные API направляются в систему, которая обслуживает соответствующую запись после миграции.                                                                                                       |
| **Какие критерии подтверждают завершение**  | Приняты единая модель и матрица мастер-систем; данные загружены и сверены; потребители переведены на целевые интерфейсы; финансовые отчёты воспроизводимы; для опубликованных наборов назначены владельцы и отражено происхождение данных. Проверены восстановление, права доступа и работа под согласованной нагрузкой. Запланированные отключения выполнены, а оставшиеся legacy-системы включены в утверждённый реестр исключений и дальнейшей миграции.                                                                                               |
